# vault-template — 볼트 템플릿

**[English](README.en.md)** | 한국어

AI 코딩 에이전트와 함께 일할 때 **세션마다 증발하는 맥락**을 남기기 위한 Obsidian 볼트 템플릿.

## 이 볼트가 푸는 문제

에이전트와의 세션은 끝나면 사라진다. 어제 밟은 함정, 지난주에 내린 결정, 세 번째로 반복한 절차가 다음 세션의 에이전트에게는 존재하지 않는다. 그래서 같은 지뢰를 다시 밟고, 같은 결정을 다시 토론하고, 같은 절차를 다시 더듬는다.

이 볼트는 그 맥락을 **에이전트가 세션 시작 때 읽는 노트 그래프**로 남긴다. 사람의 메모가 아니라 에이전트의 기억이다. 규칙은 하나다. **세션이 끝나도 남아야 하는 것만 적는다.** 새 세션의 에이전트는 `00_HOME.md`에서 시작한다.

## 5분류

노트는 다섯 종류뿐이다. 폴더가 곧 분류이고, 그래프 뷰의 색이 곧 폴더다.

| 폴더 | `type` | 무엇을 적나 | 이름 규칙 |
|---|---|---|---|
| `지뢰/` | `지뢰` | 실제로 밟은 함정. 증상 → 원인 → 해법 → 검증 | `… 지뢰`로 끝낸다 |
| `결정/` | `결정` | 내린 결정과 근거. 개정은 하단에 날짜 섹션으로 누적 | 결정 요지가 제목 |
| `런북/` | `런북` | 반복 실행하는 절차. 언제 꺼내는지가 첫 줄 | `런북 …`으로 시작한다 |
| `프로젝트/` | `project` | 진행 중인 일의 현황과 연결 고리. 지뢰·런북·결정을 링크한다 | 프로젝트 이름 |
| `인프라/` | `infra` | 프로젝트가 의존하는 서비스·계정·자원. 용도, 접근 경로, 한도, 관련 지뢰 | 서비스 이름 |

여기에 `데일리/`가 붙는다. 날짜 파일(`YYYY-MM-DD.md`, `type: daily`)에 그날의 액션과 지표를 적는다. 자동 생성해도 좋고 손으로 써도 좋다. 비어 있는 채로 시작한다.

**왜 다섯 개인가.** 지뢰는 "다시 밟지 마라", 결정은 "다시 토론하지 마라", 런북은 "다시 더듬지 마라", 프로젝트는 "지금 어디까지 왔나", 인프라는 "어디로 들어가나"다. 에이전트가 세션 첫 5분에 필요한 질문이 이 다섯이다.

인프라 노트에는 **비밀값을 적지 않는다.** 계정명과 비밀값의 *위치*만 적는다. 볼트는 공개 저장소에 올라갈 수 있다는 전제로 쓴다.

## 규약

`00_HOME.md`에 세 줄로 박혀 있다.

1. 프로젝트 작업 전 해당 노트와 연결된 지뢰를 읽는다.
2. 버전 마감·결정·새 지뢰는 즉시 노트로. 링크를 아끼지 않는다. 그래프가 곧 기억이다.
3. 요점만. 소설이 되는 순간 아무도 안 읽는다.

노트 단위 규약은 각 폴더의 `_TEMPLATE.md`에 형식으로 들어 있다. 핵심은 **제목은 색인이므로 현행화하고, 본문은 기록이므로 누적한다**는 것이다. 지뢰는 결정이나 프로젝트 노트 안에 묻지 않고 `지뢰/`에 독립 노트로 둔다. 규약 ①은 지뢰가 폴더에 있어야 작동한다.

## 설치

```bash
git clone https://github.com/Kohgane/ai-coding-mines.git
cp -r ai-coding-mines/vault-template my-vault
cd my-vault && git init -b main
```

`vault-template/` 폴더 하나가 볼트 전체다. 복사해 나온 뒤 자기 저장소로 만든다. Obsidian에서 **Open folder as vault**로 `my-vault` 폴더를 연다. 그래프 뷰를 열면 폴더별 색이 이미 잡혀 있다.

그다음:

1. `00_HOME.md`의 placeholder 링크를 자기 프로젝트 이름으로 바꾼다.
2. 각 폴더의 `_TEMPLATE.md`를 복사해 첫 노트를 만든다. `_TEMPLATE.md` 자체는 지우지 않는다.
3. 에이전트의 프로젝트 지침(예: `CLAUDE.md`)에 "세션 시작 시 `00_HOME.md`를 읽는다"를 한 줄 넣는다.

`.gitignore`는 `.obsidian/` 전체를 제외하고 `graph.json` 하나만 추적한다. workspace와 플러그인 캐시는 기기마다 달라 충돌하지만, 그래프 색 그룹은 분류 체계 그 자체라서 모든 기기에서 같아야 하기 때문이다. 이유는 `.gitignore` 주석에 적혀 있다.

## 지뢰 예시가 필요하면

이 템플릿의 `지뢰/` 폴더는 비어 있다. 같은 형식으로 쓴 실제 항목 110건이 이 저장소의 상위 폴더에 있다.

→ **[../mines/](../mines/)** — AI 코딩 지뢰 도감. Windows·PowerShell, Python·DB, Git·자동화, AI 에이전트, 배포·인프라, 쓰기 API 6장. 영어판은 [../mines/en/](../mines/en/).

그중 항목 하나를 `지뢰/_TEMPLATE.md` 형식으로 옮겨 보면 이 볼트가 어떻게 굴러가는지 바로 보인다.
