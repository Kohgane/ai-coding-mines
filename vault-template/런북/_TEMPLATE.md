## 절차
1. **단계 이름**: 무엇을 어떻게. 명령이 있으면 블록으로
   ```
   command --flag
   ```
2. **단계 이름**: 기대 결과를 함께 적는다. "성공이면 X가 보인다"
3. **검증**: 끝났다고 판정하는 근거. 응답이 아니라 재조회로
